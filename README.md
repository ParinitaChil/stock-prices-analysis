# Stock Prices Analysis (Finance Project)

## Overview
This project performs **basic analysis of historical stock price data**.  
It demonstrates how to load, clean, explore, and visualize stock market data using Python.  
This is a beginner-friendly finance/data project ideal for GitHub portfolios.

## Dataset
- Source: Public dataset of S&P 500 companies and financial metrics  
- Columns include:
  - `Name` – Company name
  - `Sector` – Industry sector
  - `MarketCap` – Market capitalization
  - `Other financial metrics`  

## Tools / Libraries
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Steps Performed
1. Load dataset into a Pandas DataFrame  
2. Explore dataset structure and basic statistics  
3. Clean data (check for missing or incorrect values)  
4. Visualize total market capitalization by sector  
5. Summarize key trends and insights

## Key Findings
- Technology and Financial sectors have the highest total market capitalization  
- Visualization highlights sector-wise differences in company size  
- Dataset is clean and ready for deeper analysis such as time series or portfolio modeling

## How to Run
1. Open `stock_prices_analysis.ipynb` in **Jupyter Notebook** or **Google Colab**  
2. Run all cells step-by-step to view the analysis and visualizations
